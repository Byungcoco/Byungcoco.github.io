## 1. 개요

<Chips items={frontmatter.chips} />

액션 게임의 타격 처리에는 충돌 감지와 별개로 "이 겹침이 공격인가, 이미 맞았는가, 맞으면 어떻게 반응하는가"를 정하는 규칙이 필요합니다. 공격 정보를 가해자가 들고 있다가 피해자에게 넘기면, 피해자는 자기 상태에 맞게 반응을 고를 수 있습니다.

공격 정보를 구조체 하나로 묶고 판정과 반응을 가해자와 피해자로 나눠, 공격 상태는 구간마다 정보만 채우면 됩니다. 한 동작 안의 여러 타격도 구간 번호만 바꾸면 같은 적을 다시 때릴 수 있습니다.

## 2. 문제

> 카타나 제로 모작의 충돌 시스템은 겹침을 알려 주는 데서 끝났고, 공격인지 아닌지는 각 오브젝트의 충돌 함수가 알아서 판단했습니다. 3D 액션에서는 공격 하나에 담기는 정보가 훨씬 많습니다. 콤보 한 동작 안에서 손·무기 같은 다른 부위로 여러 번 때리고, 타격마다 피격 반응(정면·밀려남·감전 등)과 대미지가 다릅니다. 게다가 공격 충돌체는 여러 프레임 동안 적과 겹쳐 있으므로, 한 번의 타격이 같은 적을 여러 번 때리지 않게 막아야 했습니다.

## 3. 구조 요약

공격 정보를 구조체 하나로 묶어 상태 → 부위 → 피해자 순으로 넘깁니다. 언제 어느 부위로 때릴지는 공격 상태가, 맞았는지는 가해자가, 어떻게 반응할지는 피해자가 정합니다.

```cpp
void CPartObject::Set_AttackCollider(_bool bActive, ATTACK_DESC* pDesc)
{
	CCollider* pCollider = Get_Component<CCollider>();

	if (bActive)
	{
		Begin_AttackWindow(pDesc);
	}
	else
		End_AttackWindow();

	pCollider->Set_Active(bActive);
}
// ... 코드 중략

void CPartObject::Begin_AttackWindow(ATTACK_DESC* pDesc)
{
	::memcpy(&m_CurrentAttackDesc, pDesc, sizeof(ATTACK_DESC));
	Clear_HitTargets();
	m_bAttackWindow = true;
}

void CPartObject::End_AttackWindow()
{
	m_bAttackWindow = false;
	Clear_AttackDesc();
	Clear_HitTargets();
}
```

공격 구간이 열리면 부위가 공격 정보를 복사해 두고, 때린 대상 기록을 비운 뒤 충돌체를 켭니다. 같은 구간에서 한 번 맞은 대상은 기록에 남아 다시 맞지 않고, 다음 구간이 열리면 기록이 비워져 다시 맞을 수 있습니다. 상태가 넘기는 정보는 지역 변수이므로 포인터로 들고 있지 않고 복사해 보관합니다.

공격 애니메이션 상태의 기반입니다. 매 프레임 `Apply_AttackDesc`에 "지금 몇 번째 공격 구간인가"만 넘기면, 열린 구간 번호(`m_iActiveHitWindow`)와 부위(`m_iActivePart`)를 비교해 구간이 바뀔 때만 충돌체를 바꿔 끼웁니다.

#### A. 구간이 바뀔 때만 교체

<Editor file="ComboState.cpp" fn="CComboState::Apply_AttackDesc(...)">

```cpp
void CComboState::Apply_AttackDesc(_int iNewWindow, _int iNewPart, ATTACK_DESC* pDesc)
{
	if (m_iActiveHitWindow == iNewWindow)
		return;

	if (m_iActivePart != -1 && m_iActiveHitWindow != -1)
		Set_AttackCollider(m_iActivePart, false, nullptr);

	if (iNewWindow != -1 && iNewPart != -1)
		Set_AttackCollider(iNewPart, true, pDesc);

	m_iActiveHitWindow = iNewWindow;
	m_iActivePart = iNewPart;
}
```

</Editor>

가해자 쪽 판정입니다. 공격 부위의 충돌체가 무언가와 처음 겹치면 `Try_AttackHit`(스킬은 같은 흐름의 `Try_SkillHit`)이 맞을 수 있는 상대인지 거른 뒤 피해자에게 피격을 요청합니다. `bImpact`가 켜진 공격이면 카메라를 대상 고정 연출로 바꿉니다.

```cpp
_bool CMainPlayer::Try_AttackHit(ECollideLayer eMyLayer, CCollider* pOther)
{
    if (Is_PlayerAttackLayer(eMyLayer) == false)
        return false;

    if (pOther == nullptr)
        return false;

    ECollideLayer eOtherLayer = static_cast<ECollideLayer>(pOther->Get_Layer());
    if (eOtherLayer != ECollideLayer::ENEMY_BODY)
        return false;

    CPartObject* pAttackPart = Get_PartByLayer(eMyLayer);
    if (pAttackPart == nullptr || pAttackPart->Is_AttackWindow() == false)
        return false;

    ATTACK_DESC* pDesc = pAttackPart->Get_AttackDesc();

    if (pDesc->iAttackType < 0)
        return false;

    CGameObject* pVictim = pOther->Get_Owner();

    if (pAttackPart->Is_AlreadyHitted(pVictim))
        return false;

    if (pVictim->On_Hit(static_cast<_uint>(pOther->Get_Layer()), pDesc, this) == false)
        return false;

    if (pDesc->bImpact)
    {
        CCameraMan_Targeter* pCamera = static_cast<CCameraMan_Targeter*>(Get_CameraTargeter());
        pCamera->Change_State(TargeterState::TARGETSYNC);
    }
    pAttackPart->Regist_HitTargets(pVictim);
    return true;
}
```

판정은 비용이 싼 검사부터 합니다. 내 충돌체가 공격 레이어인지, 상대가 적의 몸통인지, 공격 구간이 열려 있는지, 이번 구간에 이미 때린 대상인지를 차례로 보고, 모두 통과했을 때만 피해자에게 묻습니다(<FigRef n={3} />). 피해자가 피격을 거절하면 기록하지 않으므로, 무적 상태가 끝난 뒤 같은 구간 안에서 다시 맞을 수 있습니다.

피해자 쪽 반응입니다. `On_Hit`이 현재 상태의 피격 가능 비트(`BEATTACKED`)로 맞을지 말지를, 공격 종류(`EHitType`)로 어떤 피격 상태로 갈지를 정합니다. 가해자는 결과(`true`/`false`)만 받습니다.

```cpp
_bool CPlayer::On_Hit(_uint iCollideMyLayer, ATTACK_DESC* pDesc, CGameObject* pOther)
{
    if (m_bDead == true || m_pStatComp->Is_HealthZero() == true)
        return false;

    CActionState* pActionState = Get_Component<CActionState>();
    if (Has_Capability(pActionState->Get_CurrentCapabilities(), StateCapability::BEATTACKED) == false)
        return false;

    EHitType eType = static_cast<EHitType>(pDesc->iAttackType);

    CStateBase::STATE_START_DESC stateStartDesc = {};
    stateStartDesc.fForceAbs = pDesc->fForceAbs;
    stateStartDesc.fDragK = pDesc->fDragK;

    CTransform* pOtherTransform = pOther->Get_Component<CTransform>();
    _vector vOtherLookDir = pOtherTransform->Get_Info(TRANSFORM_INFO_STATE::LOOK);
    vOtherLookDir = ::XMVector3Normalize(vOtherLookDir);

    CTransform* pTransform = Get_Component<CTransform>();
    _float3 vScale = pTransform->Get_Scaled();
    _vector vNewLook = vOtherLookDir * -1.f;
    _vector vNewRight = ::XMVector3Normalize(::XMVector3Cross(::XMVectorSet(0.f, 1.f, 0.f, 0.f), vNewLook));
    _vector vNewUp = ::XMVector3Normalize(::XMVector3Cross(vNewLook, vNewRight));

    pTransform->Set_Info(TRANSFORM_INFO_STATE::RIGHT, vNewRight * vScale.x);
    pTransform->Set_Info(TRANSFORM_INFO_STATE::UP, vNewUp * vScale.y);
    pTransform->Set_Info(TRANSFORM_INFO_STATE::LOOK, vNewLook * vScale.z);

    if (Is_WeaponActive())
        Set_WeaponDisable();

    m_pStatComp->Add_Health(-(_int)pDesc->iDamage);
    // ... 코드 중략
    switch (eType)
    {
    case Client::EHitType::BLASTED:
        pActionState->Change_State(ENUM_TO_UINT(CPlayer::State::BEATEN_BLASTED), true, &stateStartDesc);
        break;
    // ... 코드 중략
    case Client::EHitType::HITDOWNSHORT:
        pActionState->Change_State(ENUM_TO_UINT(CPlayer::State::BEATEN_ONEHITDOWN_SHORT), true);
        break;
    case Client::EHitType::HITDOWNLONG:
        pActionState->Change_State(ENUM_TO_UINT(CPlayer::State::BEATEN_ONEHITDOWN_LONG), true);
        break;
    case Client::EHitType::WATERPRISON:
        pActionState->Change_State(ENUM_TO_UINT(CPlayer::State::BEATEN_WATERPRISON), true);
        break;
    case Client::EHitType::EARTHQUAKE:
        pActionState->Change_State(ENUM_TO_UINT(CPlayer::State::BEATEN_EARTHQAUKE), true);
        break;
    case Client::EHitType::UNIVERSALPULL:
        pActionState->Change_State(ENUM_TO_UINT(CPlayer::State::BEATEN_UNIVERSALPULLSTART), true);
        break;
    case Client::EHitType::ELECTRICKSHOCK:
        pActionState->Change_State(ENUM_TO_UINT(CPlayer::State::BEATEN_ELECTRICSHOCK), true);
        break;
    case Client::EHitType::PAIN_SPECIALSKILL:
        pActionState->Change_State(ENUM_TO_UINT(CPlayer::State::BEATEN_PAINSPECIALSKILL), true);
        break;
    default:
        break;
    }

    return true;
}
```

## 5. 피드백

**같은 판정 코드를 가해자마다 따로 들고 있었습니다.** 플레이어, 일반 적, 수리검·화염구·상어탄 같은 스킬 오브젝트가 각자 `Try_Hit`을 갖고 "레이어 → 구간 → 중복 → 피격 요청 → 기록" 순서를 거의 그대로 반복합니다. 그래서 판정 규칙 하나를 바꾸려면 모든 가해자를 고쳐야 합니다. 판정을 한 곳(판정 시스템)으로 모으고 가해자는 충돌 사실만 넘겼다면, 규칙이 한 군데에만 남았을 것입니다.

남은 개선점입니다.

- 공격 수치가 상태 코드에 들어 있습니다. 데이터(프리셋)로 빼고 상태는 프리셋 번호만 갖게 하면 빌드 없이 조정할 수 있습니다.
- `ATTACK_DESC`로 넉백 세기를 넘기지만 상태 시작 함수가 아직 읽지 않아, 피격 상태마다 고정값을 씁니다.
