## 1. 개요

<Chips items={frontmatter.chips} />

2D 플랫포머의 지형 충돌은 보통 사각형 겹침을 밀어내는 방식으로 처리하지만, 경사로나 한쪽 방향으로만 막히는 발판에는 별도의 규칙이 필요합니다. 경사로는 선분의 높이를 직접 계산하고, 통과 발판은 이동 방향에 따라 충돌 여부를 정하는 것이 일반적입니다.

지형마다 반응을 나눈 덕분에 새 지형은 클래스 하나로 추가할 수 있고, 캐릭터는 어떤 지형 위에 있는지 몰라도 접지 개수만으로 착지를 판단합니다.

## 2. 문제

> 맵에는 평평한 바닥과 벽 말고도 경사로와, 아래에서는 뚫고 올라가고 위에서는 밟을 수 있는 통과 발판이 있습니다. 모든 지형을 사각형(AABB)으로 밀어내면 경사로에서 캐릭터가 계단처럼 튀고, 통과 발판에서는 아래에서 점프해도 머리가 막혔습니다. 바닥·경사로·발판에 동시에 걸치는 순간도 있어서, "땅에 서 있는가"를 지형 하나의 충돌 결과만으로 판단할 수 없었습니다.

## 3. 구조 요약

충돌했을 때의 반응은 지형이 스스로 처리합니다. 벽·경사로·통과 발판이 각자 `OnCollision`에서 캐릭터 위치를 보정하고 접지 개수를 늘리거나 줄이며, 캐릭터는 접지 개수가 0보다 큰지만 봅니다.

사각형 지형입니다. 닿은 오브젝트와 들어온 축을 `m_CollidedObjects`에 기억해 두고, 위에서 밟았을 때만 `OnCollisionEnter`에서 접지로 셌다가 `OnCollisionExit`에서 되돌립니다. 닿아 있는 동안에는 `HorizontalCollide`·`VerticalCollide`로 겹친 만큼 밀어냅니다.

#### A. 겹침이 작은 축으로 밀어내기

<Editor file="CWall.cpp" fn="OnCollisionEnter(...)">

```cpp
void CWall::OnCollisionEnter(CColliderComponent *_pOtherComp)
{
	// ... 코드 중략
	Vector2 Delta = OtherPosition - RectPosition;
	Vector2 AbsDelta{ fabs(Delta.x), fabs(Delta.y) };

	float Overlapped_X = (RectHalfSize.x + OtherHalfSize.x) - AbsDelta.x;
	float Overlapped_Y = (RectHalfSize.y + OtherHalfSize.y) - AbsDelta.y;

	if (Overlapped_X < Overlapped_Y)
	{
 		VerticalCollide(pOtherObject, Delta.x, Overlapped_X);
 		m_CollidedObjects.insert(unordered_map<CObject *, CollisionAxis>::value_type(pOtherObject, CollisionAxis::VERT));
		if (eType == ObjectType::GANGSTER || eType == ObjectType::GRUNT || eType == ObjectType::POMP)
			static_cast<CMonster *>(pOtherObject)->AddCollidedGround(this, CollisionAxis::VERT);
	}
	else
	{
		// Rect기준 수평
		HorizontalCollide(pOtherObject, Delta.y, Overlapped_Y);
		if (Delta.y < 0.f)
		{
			m_CollidedObjects.insert(unordered_map<CObject *, CollisionAxis>::value_type(pOtherObject, CollisionAxis::HORZ));
			pOtherObject->AddGrounded(1);
			if (eType == ObjectType::GANGSTER || eType == ObjectType::GRUNT || eType == ObjectType::POMP)
				static_cast<CMonster *>(pOtherObject)->AddCollidedGround(this, CollisionAxis::HORZ);
		}
		// ... 코드 중략
	}
}
```

<Editor file="CWall.cpp" fn="OnCollisionExit(...)">

```cpp
void CWall::OnCollisionExit(CColliderComponent *_pOtherComp)
{
	// ... 코드 중략
	unordered_map<CObject *, CollisionAxis>::iterator itr = m_CollidedObjects.find(pOtherObject);
	if (itr != m_CollidedObjects.end())
	{
		if (itr->second == CollisionAxis::HORZ)
		{
			_pOtherComp->GetOwner()->AddGrounded(-1);
		}
		m_CollidedObjects.erase(itr);
	}
}
```

</Editor>

땅에 있는지를 `bool` 하나로 두면, 바닥 두 개에 걸쳐 있다가 하나에서 벗어나는 순간 공중으로 판정됩니다. 그래서 닿은 바닥 수를 세고, 0보다 클 때 땅에 있다고 봅니다. 벽은 바닥으로 닿았던 오브젝트만 기억해 두었다가, 떨어질 때 개수를 줄입니다.

기울어진 선분 지형입니다. 사각형 대신 양 끝점(`vFrom`·`vTo`)으로 만든 1차 함수로 `OnCollision`에서 발밑 높이를 구해 위치를 보정하고, 선분 범위를 벗어나면 `OnCollisionExit`에서 접지를 풀어 줍니다.

#### A. 1차 함수로 높이 보정

<Editor file="CSlopeLine.cpp" fn="OnCollision(...)">

```cpp
void CSlopeLine::OnCollision(CColliderComponent *_pOtherComp)
{
	// ... 코드 중략
	CurDot = { ObjPos.x + ObjSize.x * 0.25f, ObjPos.y + (ObjSize.y * 0.5f)};

	fMinX = min(x1, x2);
	fMinY = max(y1, y2);
	fMaxX = max(x1, x2);
	fMaxY = min(y1, y2);

	if (CurDot.x < fMinX || CurDot.x > fMaxX)
		return;

	fSlope = (fMaxY - fMinY) / (fMaxX - fMinX);
	fValueY = fMinY + fSlope * (CurDot.x - fMinX);

	float fDist = CurDot.y - fValueY;

	if (fDist >= 0.f)
	{
		if (!pObj->IsLine())
		{
			pObj->AddGrounded(1);
			pObj->SetOnLine(true);
			pObj->SetVel_X(DEFAULT_OBJECT_SPPED*0.8f);
			if (eType == ObjectType::GANGSTER || eType == ObjectType::GRUNT || eType == ObjectType::POMP)
				static_cast<CMonster *>(pObj)->AddCollidedGround(this, CollisionAxis::HORZ);
		}

		pObj->AddPos_Y(-fDist);
	}
	// ... 코드 중략
}
```

</Editor>

아래에서는 통과하고 위에서는 밟을 수 있는 발판입니다. `Update` 시작에 저장한 이전 위치(`GetPrevPos()`)와 비교해 내려오는 중일 때만 착지시키고, 플레이어가 내려가려는 중인지는 `IsJumpThrough()`로 확인합니다.

#### A. 내려올 때만 착지

```cpp
void CJumpThroughLine::OnCollision(CColliderComponent *_pOtherComp)
{
	// ... 코드 중략
	float fDist_Y = ObjPrevPos.y - ObjNowPos.y;
	if (fDist_Y > 0.f)
		return;

	LINE lineInfo = Get_Info();
	float Line_Y = lineInfo.vFrom.y;
	if (lineInfo.vFrom.y <= ObjNowPos.y)
		return;

	Vector2 ObjBottomPrev = ObjPrevPos + ObjSize * 0.5f;
	Vector2 ObjBottomNow = ObjNowPos + ObjSize * 0.5f;

	float fPene = ObjBottomNow.y - Line_Y;

	if (fPene >= 0)
	{
		pObject->AddPos_Y(-fPene);
		if (!pObject->IsLine())
		{
			pObject->AddGrounded(1);
			pObject->SetOnLine(true);
			SetThrough(true);
			if (pObject->GetType() == ObjectType::GANGSTER || pObject->GetType() == ObjectType::GRUNT || pObject->GetType() == ObjectType::POMP)
				static_cast<CMonster *>(pObject)->AddCollidedGround(this, CollisionAxis::HORZ);
		}
	}
	// ... 코드 중략
}
```

## 5. 피드백

**지형 클래스가 몬스터 종류를 하나하나 알고 있어야 했습니다.** 벽·경사로·발판 모두 `GANGSTER || GRUNT || POMP`를 확인해 몬스터에게 닿은 바닥을 알려 주므로, 몬스터가 하나 늘면 지형 클래스를 전부 고쳐야 합니다. 몬스터 공통 기반 타입이나 "닿은 바닥을 알아야 하는가" 플래그로 판별했다면 지형이 몬스터 종류를 몰라도 됐습니다.

남은 개선점입니다.

- 접지 개수 증감·선 위 여부·몬스터 알림이 세 지형 클래스에 반복되어, 한쪽만 고치면 지형마다 동작이 달라질 수 있습니다.
- 착지·이탈 처리를 `CLine` 공통 함수로 올리고, 파생 클래스는 높이 계산만 다르게 하는 편이 낫습니다.
