## 1. 개요

<Chips items={frontmatter.chips} />

파티클 시스템은 수명이 짧은 작은 입자를 많이 뿌려 불꽃·피·연기 같은 효과를 만드는 방식입니다. 입자마다 위치·속도·수명을 두고 매 프레임 적분하며, 이펙트 사이의 차이는 보통 클래스가 아니라 방출·움직임·색 변화 파라미터로 표현합니다.

이펙트의 차이를 옵션 데이터로 표현해, 전기·피·불꽃은 같은 클래스에 프리셋만 바꿔 만들고 새 이펙트는 프리셋 함수 하나로 추가할 수 있습니다.

## 2. 문제

> 총에 맞을 때의 불꽃, 피, 전기, 깨지는 유리, 폭발처럼 짧게 나왔다 사라지는 이펙트가 매우 많았습니다. 이펙트마다 클래스를 만들면 종류가 늘 때마다 코드도 늘어납니다. 이펙트마다 퍼지는 방식(직선, 포물선, 흔들림, 나선)과 색 변화가 다르고, 리소스 형태도 점, 조각 이미지, 연속 프레임 애니메이션으로 제각각이었습니다. 보스 돌진은 너무 빨리 지나가서 움직임이 잘 보이지 않았습니다.

## 3. 구조 요약

이펙트의 차이는 클래스가 아니라 옵션 데이터로 표현했습니다. 전기·피·불꽃은 모두 같은 점 파티클 클래스이고 옵션 프리셋만 다릅니다. 클래스는 리소스 형태(점·조각·애니메이션)에 따라서만 나눴습니다.

`EffectOptions`는 이펙트 하나의 모양을 정하는 수치를 모은 구조체입니다. 움직임 모드 `eMode`, 입자 수, 수명·크기·속도 범위, 시작·끝 색(`colorStart`·`colorEnd`), 모드별 계수, 블렌드 방식 `eBlendmode`를 담습니다. 새 이펙트는 이 값을 채우는 프리셋 함수 하나로 추가합니다.

점 파티클은 CPU에서 입자(`m_vecParticles`)를 시뮬레이션하고, 살아 있는 입자만 동적 정점 버퍼 `m_pVB`에 채워 포인트 스프라이트로 한 번에 그립니다. `Spawn_Pooling`이 옵션을 받아 바로 발사하고, `Particle_Update`가 모드별 가속도와 적분을, `Ready_VB`가 색 보간과 버퍼 갱신을 맡습니다. 살아 있는 입자가 없으면 `DEAD`를 반환합니다.

void CEffect_Pixel::Do_Once()
{
    const int iIndex = (std::min)(m_tOption.iPixelCount, (_int)(m_vecParticles.size() - m_iAliveCount));
    for (int i = 0; i < iIndex; ++i)
    {
        ParticleInfo &tInfo = m_vecParticles[i];

        if (tInfo.bAlive)
            continue;

        tInfo.vPosition = _vec3{ 0.f, 0.f, 0.f };
        // 방향/속도
        _vec3 vDir = randomDir_HalfSphere();
        _float fSpeed = randRange(m_tOption.fSpeed_Min, m_tOption.fSpeed_Max);
        tInfo.vVelocity = vDir * fSpeed;

        tInfo.fDurationTime = 0.f;
        tInfo.fLifeTime = randRange(m_tOption.fLife_Min, m_tOption.fLife_Max);
        tInfo.fSize = randRange(m_tOption.fSize_Min, m_tOption.fSize_Max);
        tInfo.colorStart = m_tOption.colorStart;
        tInfo.colorEnd = m_tOption.colorEnd;
        tInfo.bAlive = true;
        ++m_iAliveCount;
    }
}

<Editor file="CEffect_Pixel.cpp" fn="CEffect_Pixel::randomDir_HalfSphere()">

```cpp
D3DXVECTOR3 CEffect_Pixel::randomDir_HalfSphere() const
{
	float u = rand01() * 2.f - 1.f;      // cos theta in [-1,1]
	float phi = rand01() * 6.28f;
	float r = sqrtf((std::max)(0.f, 1.f - u * u));
	D3DXVECTOR3 d(r * cosf(phi), fabsf(u), r * sinf(phi)); // y>=0
	D3DXVec3Normalize(&d, &d);
	return d;
}
```

</Editor>

스폰 데이터로 옵션을 받아 입자를 배치하고 그 자리에서 발사합니다. 방향은 반구 위에서 고르게 뽑아 위쪽으로 퍼지게 했습니다. 입자가 모두 죽으면 `DEAD`를 반환하고, 풀이 이를 회수합니다.

#### B. 모드별 가속도

<Editor file="CEffect_Pixel.cpp" fn="CEffect_Pixel::Particle_Update(...)">

```cpp
void CEffect_Pixel::Particle_Update(_float fDeltaTime)
{
    // ... 코드 중략
    for (ParticleInfo &tElement : m_vecParticles)
    {
        // ... 코드 중략
        const float fNoiseFrequency = m_tOption.fNoiseFreq * 6.28f;

        // 가속 구성
        _vec3 fAccelVelocity{ 0,0,0 };
        switch (m_tOption.eMode)
        {
        case EffectMode::LINEAR:
        {
            fAccelVelocity += (-m_tOption.fDrag) * tElement.vVelocity;
        } break;
        case EffectMode::GRAVITY_ARC:
        {
            fAccelVelocity += _vec3{ 0, -9.8f, 0 };
            fAccelVelocity += (-m_tOption.fDrag) * tElement.vVelocity;
        } break;
        case EffectMode::CURVE_NOISE:
        {
            _vec3 vSrc = tElement.vVelocity;
            _float fLength = ::D3DXVec3Length(&vSrc);
            if (fLength > 1e-4f /*Epsilon*/)
            {
                vSrc /= fLength;
                _vec3 vWorldUp{ 0, 1.f, 0 };
                _vec3 vCrossResult;
                ::D3DXVec3Cross(&vCrossResult, &vSrc, &vWorldUp);
                // ... 코드 중략
                ::D3DXVec3Normalize(&vCrossResult, &vCrossResult);
                float fSin = sinf(tElement.fPhase + fNoiseFrequency * tElement.fDurationTime);
                fAccelVelocity += vCrossResult * (m_tOption.fNoiseStrength * fSin);
            }
            fAccelVelocity += (-m_tOption.fDrag) * tElement.vVelocity;
        } break;
        // ... 코드 중략
        }

        tElement.vVelocity += fAccelVelocity * fDeltaTime;
        tElement.vPosition += tElement.vVelocity * fDeltaTime;

        tElement.fDurationTime += fDeltaTime;
        if (tElement.fDurationTime >= tElement.fLifeTime)
        {
            tElement.bAlive = false;
            --m_iAliveCount;
        }
    }
}
```

</Editor>

HRESULT CEffect_Pixel::Ready_VB()
{
	if (!m_pVB || m_iAliveCount <= 0)
        return E_FAIL;

	VTXPIXELCOLOR *vtx = nullptr;
	m_pVB->Lock(0, sizeof(VTXPIXELCOLOR) * m_iVBCapacity, (void **)&vtx, D3DLOCK_DISCARD);

	int iIndex{ 0 };
	for (ParticleInfo &tElement : m_vecParticles)
	{
		if (!tElement.bAlive)
			continue;

		// 경과 시간 / 생명 시간으로 색깔 보간!
		float fSrc = (std::min)(1.f, (std::max)(0.f, tElement.fDurationTime / tElement.fLifeTime));
		vtx[iIndex].vPosition = tElement.vPosition;
		vtx[iIndex].dwColor = ToColor(LerpColor(tElement.colorStart, tElement.colorEnd, fSrc));
		vtx[iIndex].fSize = tElement.fSize;
		++iIndex;
	}
	m_pVB->Unlock();
    return S_OK;
}

조각 파티클은 같은 시뮬레이션에 모양이 있는 텍스처 조각(유리·드론 파편 등)을 붙인 것으로, 옵션은 `SpriteParticleOptions`로 받습니다. 입자마다 각도 `fAngle`로 회전한 사각형을 CPU에서 만들어 정점·인덱스 버퍼에 담습니다.

#### A. 회전하는 조각

<Editor file="CEffect_Pixel_Sprite.cpp" fn="CEffect_Pixel_Sprite::Ready_VB()">

```cpp
HRESULT CEffect_Pixel_Sprite::Ready_VB()
{
    // ... 코드 중략
    for (ParticleInfo &tElement : m_vecParticles)
    {
        // ... 코드 중략
        _float fHalf = tElement.fSize * 0.5f;
        _float fCos = cosf(tElement.fAngle);
        _float fSin = sinf(tElement.fAngle);

        _vec3 vLocalOffset_0{ -fHalf, fHalf, 0.f };
        _vec3 vLocalOffset_1{ fHalf, fHalf, 0.f };
        _vec3 vLocalOffset_2{ fHalf, -fHalf, 0.f };
        _vec3 vLocalOffset_3{ -fHalf, -fHalf, 0.f };

        auto GetRotate = [&](const _vec3 &v)->_vec3
        { return _vec3(v.x * fCos - v.y * fSin, v.x * fSin + v.y * fCos, 0.f); };

        vtx[iIndex].vPosition = tElement.vPosition + GetRotate(vLocalOffset_0);
        vtx[iIndex].vTexUV = { 0.f, 0.f };
        ++iIndex;
        vtx[iIndex].vPosition = tElement.vPosition + GetRotate(vLocalOffset_1);
        vtx[iIndex].vTexUV = { 1.f, 0.f };
        ++iIndex;
        vtx[iIndex].vPosition = tElement.vPosition + GetRotate(vLocalOffset_2);
        vtx[iIndex].vTexUV = { 1.f, 1.f };
        ++iIndex;
        vtx[iIndex].vPosition = tElement.vPosition + GetRotate(vLocalOffset_3);
        vtx[iIndex].vTexUV = { 0.f, 1.f };
        ++iIndex;
    }
	// ... 코드 중략
}
```

파티클이 아니라 한 장짜리 연속 프레임을 재생하는 이펙트로, 폭발이나 피 튀김처럼 한 덩어리로 보이는 효과에 씁니다. 각도·크기·종류는 `EFFECTINFO`로 받고, 애니메이션이 끝나면 `DEAD`를 반환합니다. 빌보드로 세운 뒤 절두체 안에 있을 때만 그립니다.

void CBoss::Record_AfterImage()
{
	AfterImage tData;
	tData.vRight = GetTransform()->Get_Info(INFO::INFO_RIGHT);
	tData.vUp = GetTransform()->Get_Info(INFO::INFO_UP);
	tData.vLook = GetTransform()->Get_Info(INFO::INFO_LOOK);
	tData.vPos = GetTransform()->Get_Info(INFO::INFO_POS);
	tData.iFrame = m_pTextureCom->Get_Frame().m_iCurrentTex;

	m_dequeAfterImage.push_back(tData);
	if (m_dequeAfterImage.size() > m_iMaxAfterImage)
		m_dequeAfterImage.pop_front();
}

void CBoss::Update_AfterImage(const _float fDeltaTime)
{
	if (m_dequeAfterImage.size() <= 0)
		return;

	deque<AfterImage>::iterator itr = m_dequeAfterImage.begin();
	for (;itr != m_dequeAfterImage.end(); )
	{
		itr->fLife += fDeltaTime;
		if (itr->fLife >= m_fLifeLimit)
			itr = m_dequeAfterImage.erase(itr);
		else
			++itr;
	}
}

## 5. 피드백

**이펙트의 움직임이 모드 하나를 고르는 데 묶여 있습니다.** 포물선과 흔들림처럼 여러 효과를 섞을 수 없어서, 원하는 모양이 나오지 않으면 모드를 새로 추가해야 했습니다. 옵션 데이터로 이펙트를 늘리는 구조는 잘 동작했지만, 표현력은 모드 목록을 넘어서지 못했습니다.

남은 개선점입니다.

- 점 파티클과 조각 파티클이 시뮬레이션 코드를 각자 복사해 갖고 있어, 한쪽을 고치면 다른 쪽도 맞춰 고쳐야 합니다. 조각 파티클은 입자마다 텍스처를 바꿔 따로 그리므로, 조각을 아틀라스 한 장에 모으면 한 번에 그릴 수 있습니다.
- 점 파티클의 정점 버퍼는 옵션의 입자 수와 상관없이 128개로 만들어서, 옵션의 개수가 버퍼 크기를 넘지 않는다는 보장이 없습니다.
- 입자별 위상(`fPhase`)이 모두 0이라 노이즈·나선 모드에서 같은 박자로 흔들리고, 나선 모드는 나선 주파수 옵션(`fSpiralFreq`) 대신 노이즈 주파수를 씁니다.
- 잔상을 그린 뒤 텍스처 스테이지 상태는 복원하지만 블렌드 상태(`ALPHABLENDENABLE`, `DESTBLEND`)는 바꾼 채로 둡니다.
