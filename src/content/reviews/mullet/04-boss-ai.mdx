## 1. 개요

<Chips items={frontmatter.chips} />

유한 상태 기계(FSM)는 객체가 한 번에 하나의 상태에 머물다가 조건에 따라 다른 상태로 넘어가는 구조입니다. 보스 패턴은 보통 준비·실행·회복처럼 단계를 나눠 플레이어에게 공격을 읽고 대응할 틈을 주고, 쿨타임으로 같은 패턴이 몰리지 않게 조절합니다.

쿨타임 길이를 패턴마다 다르게 두어 고정 우선순위로도 세 패턴이 번갈아 나옵니다. 준비 → 실행 → 회복 단계와 감쇠 이동 덕분에 방향을 틀 때도 움직임이 딱딱하게 꺾이지 않습니다.

## 2. 문제

> 보스는 돌진, 미사일 일제 사격, 부채꼴 기관총 세 가지 패턴을 쓰고, 옥상 스테이지(사각형 경로 순회)와 도로 스테이지(좌우로 오가며 달리는 플레이어를 따라옴) 두 곳에 등장합니다. 패턴을 무작위로 고르면 같은 패턴이 연달아 나오거나 특정 패턴이 오래 나오지 않을 수 있습니다. 또 속도를 한 번에 바꾸면 방향을 틀 때 움직임이 딱딱하게 꺾였습니다.

## 3. 구조 요약

보스 하나 안에서 상태(무엇을 하는가)와 이동(어떻게 움직이는가)을 나눴습니다. 상태는 열거형과 Enter / Update / Exit 함수로 돌아가고, 이동은 상태가 정한 목표 속도를 감쇠 보간으로 따라갑니다. 패턴 수치는 설정 구조체 하나에 모았습니다.

| `Update_Dash` / `Bullet` / `Missile` | 준비 → 실행 → 회복 단계 진행, 끝나면 쿨타임 설정 |
| `RigidBodyConfig` | 속도·단계별 시간·탄 수·퍼짐 각도·쿨타임 등 패턴 수치 |
| `SmoothDamp` / `UpdateSpeed` | 목표 속도를 진동 없이 따라가는 실제 속도 계산 |
| 경로 모드 (`RECT` / `LR`) | 스테이지별 이동 목표. 상태 코드는 그대로 두고 목표만 바꿈 |

</div>

상태는 열거형 `m_eCurrentState` 하나와 상태별 Enter / Update / Exit 함수로 표현합니다. 전환은 `ChangeState`가, 현재 상태의 갱신은 `UpdateState`가 맡습니다. 상태(또는 단계)에 머문 시간은 `m_fStateDuration`에, 돌진·미사일·기관총의 쿨타임은 `m_fCooldown`에 둡니다.

#### A. Exit → Enter

<Editor file="CBoss.cpp" fn="CBoss::ChangeState(...), CBoss::UpdateState(...)">

```cpp
void CBoss::ChangeState(State _e)
{
	if (m_eCurrentState == _e)
		return;

	switch (m_eCurrentState)
	{
	case State::IDLE:		Exit_Idle();    break;
	case State::MOVE:		Exit_Move();    break;
	case State::DASH:		Exit_Dash();    break;
	case State::BULLET:		Exit_Bullet();	break;
	case State::MISSILE:	Exit_Missile(); break;
	}

	m_eCurrentState = _e;
	m_fStateDuration = 0.f;

	switch (m_eCurrentState)
	{
	case State::IDLE:		Enter_Idle();		break;
	case State::MOVE:		Enter_Move();		break;
	case State::DASH:		Enter_Dash();		break;
	case State::BULLET:		Enter_Bullet();		break;
	case State::MISSILE:	Enter_Missile();	break;
	case State::DEATH:		Enter_Death();		break;
	}
}
void CBoss::UpdateState(const float _fDeltaTime)
{
	switch (m_eCurrentState)
	{
	case State::IDLE:		Update_Idle(_fDeltaTime);		break;
	case State::MOVE:		Update_Move(_fDeltaTime);		break;
	case State::DASH:		Update_Dash(_fDeltaTime);		break;
	case State::BULLET:		Update_Bullet(_fDeltaTime);		break;
	case State::MISSILE:	Update_Missile(_fDeltaTime);	break;
	case State::DEATH:		Update_Death(_fDeltaTime);		break;
	}
}
```

</Editor>

전환할 때는 언제나 이전 상태의 정리(`Exit`)가 먼저이고 새 상태의 준비(`Enter`)가 나중입니다. 기관총처럼 반복 재생하던 소리는 `Exit`에서 멈추므로, 어느 상태로 넘어가든 정리가 빠지지 않습니다.

```cpp
void CBoss::Update_Missile(_float fDeltaTime)
{
	// ... 코드 중략
	switch (m_iPhase)
	{
	// ... 코드 중략
	case 1: // Fire volley (한 볼리 안에서 N발, 간격 fMis_Interval)
		if (m_iShots < m_tRigidbodyConfig.iMis_PerVolley &&
			m_fStateDuration >= m_tRigidbodyConfig.fMis_Interval)
		{
			m_fStateDuration = 0.f;

			// 한 발 발사
			Spawn_Missile();
			++m_iShots;
		}

		// 볼리 완료 → 다음 단계로
		if (m_iShots >= m_tRigidbodyConfig.iMis_PerVolley)
		{
			m_iPhase = 2;
			m_fStateDuration = 0.f;
		}
		break;

	case 2: // Volley gap (다음 볼리까지 휴지)
		if (m_fStateDuration >= m_tRigidbodyConfig.fMis_VolleyGap)
		{
			m_fStateDuration = 0.f;
			++m_iVolley;

			if (m_iVolley < m_tRigidbodyConfig.iMis_Volley)
			{
				// 다음 볼리 시작
				m_iPhase = 1;
				m_iShots = 0;
			}
			else
			{
				// 모든 볼리 끝 → 리커버
				m_iPhase = 3;
			}
		}
		break;

	case 3: // Recover
		if (m_fStateDuration >= m_tRigidbodyConfig.fMis_Recover)
		{
			Set_Cooldown(1, m_tRigidbodyConfig.fMis_Cooldown);
			ChangeState(State::IDLE);
		}
		break;
	}
}
```

상태는 목표 속도(`m_fTargetVel_X`·`Z`)만 정하고, 실제 속도는 축마다 `SmoothDamp`로 보간한 뒤 `UpdateSpeed`에서 최대 속도로 제한합니다. 경로 모드 `m_ePathMode`(사각형 순회 또는 좌우 왕복)에 따라 목표만 달라지고, 도로 모드에서는 `Maintain_LR_Anchor_Z`가 플레이어와의 Z 거리를 유지합니다.

#### A. 감쇠 보간

<Editor file="CBoss.h" fn="SmoothDamp">

```cpp
struct SmoothDamp
{
	_float fVelocity{ 0.f };
	_float fSmoothTime{ 0.10f };
	_float Step(_float fCurrent, _float fTarget, _float fDeltaTime)
	{
		_float _fSmoothTime = (std::max)(1e-4f, fSmoothTime);
		_float fOmega = 2.0f / _fSmoothTime;
		_float fX = fOmega * fDeltaTime;
		_float fExp = 1.0f / (1.0f + fX * (1.0f + 0.48f * fX + 0.235f * fX * fX));
		_float fChange = fCurrent - fTarget;
		_float tmp = (fVelocity + fOmega * fChange) * fDeltaTime;
		fVelocity = (fVelocity - fOmega * tmp) * fExp;
		return fTarget + (fChange + tmp) * fExp;
	}
};
```

</Editor>

```cpp
void CBoss::UpdateSpeed(const float _fDeltaTime)
{
	m_fVelocity_X = m_tDamping_X.Step(m_fVelocity_X, m_fTargetVel_X, _fDeltaTime);
	m_fVelocity_Z = m_tDamping_Z.Step(m_fVelocity_Z, m_fTargetVel_Z, _fDeltaTime);

	const _float &fMaxMove = m_tRigidbodyConfig.fMoveSpeed;
	const _float &fMaxDash = m_tRigidbodyConfig.fDash_Speed;
	const _float fMaxSpeed = (m_eCurrentState == State::DASH) ? fMaxDash : fMaxMove;
	// ... 코드 중략
	const _float fCurSpeed = std::sqrt(m_fVelocity_X * m_fVelocity_X + m_fVelocity_Z * m_fVelocity_Z);
	if (fCurSpeed > fMaxSpeed)
	{
		_float k = fMaxSpeed / fCurSpeed;
		m_fVelocity_X *= k;
		m_fVelocity_Z *= k;
	}
}
```

#### B. 도로 모드 Z 유지

```cpp
void CBoss::Maintain_LR_Anchor_Z(_float fK, _float fMaxZ)
{
	if (!m_pPlayer)
		return;

	const _float fAnchor_Z = m_pPlayer->Get_Position().z + m_fOffset_FromPlayer_Z;
	const _float fDz = fAnchor_Z - Get_Position().z;

	const _float fCorr = std::clamp(fK * fDz, -fMaxZ, fMaxZ);

	m_fTargetVel_Z = fCorr;
}
```

## 5. 피드백

**패턴 선택 규칙이 `Update_Idle`과 `Update_Move` 안에 똑같이 복사되어 있습니다.** "다음에 무엇을 할지" 정하는 판단이 각 상태 안에 섞여 있어서, 규칙을 바꾸려면 상태마다 고쳐야 합니다. 판단과 실행을 나누고 선택 규칙을 한곳에 두었어야 했습니다.

남은 개선점입니다.

- 우선순위가 고정 순서라 쿨타임이 동시에 끝나면 항상 돌진이 먼저 나오고, 플레이어와의 거리나 직전 패턴은 고려하지 않습니다.
- 패턴 단계(`m_iPhase`, 0부터 3까지)와 쿨타임 번호(`m_fCooldown[0~2]`)가 숫자 상수입니다. 열거형으로 바꿔야 실수가 줄어듭니다.
- 설정 구조체에 쓰이지 않는 값(`fCornerSlowDown`, `fBul_Speed`, `fDesired` 등)이 남아 있고, 탄속은 `Spawn_Bullet` 안의 스테이지별 상수로 정합니다. 수치를 한곳에서 조정하려던 의도와 어긋납니다.
