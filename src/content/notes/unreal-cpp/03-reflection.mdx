## Reflection이란?

프로그램에서 런타임 시점에 사용되는 자신의 구조와 행위를 관리(type instrospection)하고 수정할 수 있는 프로세스를 의미한다. type instrospection은 런타임에 객체의 형(type)을 확인할 수 있는 능력을 의미한다.
즉, <strong>런타임에 타입정보를 탐색하고 조작</strong>할 수 있는 기능이며 <strong>객체의 타입, 메서드, 속성, 필드 등을 실행 중에 확인</strong>하거나 <strong>수정</strong>할 수 있음을 뜻한다. 간단하게 리플렉션을 지원하는 C#예제를 살펴보며 느낌을 얻어보자.

### C#에서의 Reflection 사용 예제

- <strong>타입 정보 탐색</strong> System.Type: 타입 정보 제공

```csharp
using System;

class Example
{
    public int Number { get; set; }
    public void Print() => Console.WriteLine("Hello, Reflection!");
}

class Program
{
    static void Main()
    {
        // 객체 타입 정보 가져오기
        Type type = typeof(Example);
        
        // 타입 이름 출력
        Console.WriteLine("Type Name: " + type.Name);

        // 속성 출력
        foreach (var property in type.GetProperties())
        {
            Console.WriteLine("Property: " + property.Name);
        }

        // 메서드 출력
        foreach (var method in type.GetMethods())
        {
            Console.WriteLine("Method: " + method.Name);
        }
    }
}
```

Property: Number

Method: Print

Method: ToString

Method: Equals

Method: GetHashCode

Method: GetType

[ToString, Equals, GetHashCode, GetType ==&gt; 클래스내 기본제공 함수]

- <strong>런타임 객체 생성</strong> Activator.CreateInstance를 사용해 객체를 런타임에 생성

```csharp
using System;

class Example
{
    public int Number { get; set; }
}

class Program
{
    static void Main()
    {
        // 런타임에 객체 생성
        Type type = typeof(Example);
        object instance = Activator.CreateInstance(type);

        // 속성 값 설정 및 출력
        var property = type.GetProperty("Number");
        property.SetValue(instance, 42);
        Console.WriteLine("Number: " + property.GetValue(instance));
    }
}
```

<div class="note-box">

Number

:

42

</div>

- <strong>메서드 호출</strong>

```csharp
using System;

class Example
{
    public void PrintMessage(string message)
    {
        Console.WriteLine("Message: " + message);
    }
}

class Program
{
    static void Main()
    {
        // 런타임에 메서드 호출
        Type type = typeof(Example);
        object instance = Activator.CreateInstance(type);

        var method = type.GetMethod("PrintMessage");
        method.Invoke(instance, new object[] { "Hello, Reflection!" });
    }
}
```

<div class="note-box">

Message: Hello, Reflection!

</div>

- <strong>필드 값 읽기/쓰기</strong> 클래스의 필드를 읽거나 변경 가능

```csharp
using System;

class Example
{
    private int _hiddenField = 10;
}

class Program
{
    static void Main()
    {
        Type type = typeof(Example);
        object instance = Activator.CreateInstance(type);

        var field = type.GetField("_hiddenField", 
            System.Reflection.BindingFlags.NonPublic | System.Reflection.BindingFlags.Instance);
        
        // 필드 값 읽기
        Console.WriteLine("Hidden Field Value: " + field.GetValue(instance));
        
        // 필드 값 변경
        field.SetValue(instance, 42);
        Console.WriteLine("Updated Field Value: " + field.GetValue(instance));
    }
}
```

<div class="note-box">

Hidden Field Value: 10

Updated Field Value: 42

</div>

## 1. UE에서의 리플렉션 시스템

엔진과 에디터 함수 기능을 제공하는 다양한 <strong>매크로를 사용하여 클래스를 캡슐화</strong>한다. 이를 통해 표준 C++ 클래스, 함수, 변수를 활용하면서도, UObject 기반 시스템으로 에디터의 디테일 패널, 가비지 컬렉션, 블루프린트 등에서 동작을 정의할 수 있다. 이러한 구조는 <strong>"프로퍼티 시스템"</strong>으로 불리며, UnrealHeaderTool(UHT)에 의해 <strong>컴파일 타임전에 메타정보를 생성</strong>하여 리플렉션 시스템과 통합된다. 이 최적화된 구조 덕분에 성능 손실이 적고, 다양한 시스템과의 효율적인 연동이 가능하다.

- 리플렉션 데이터 수집 대상이 되려면 <strong>generated.h를 추가</strong>해 UHT에 알려야 함
- 리플렉션된 프로퍼티가 아닌 것은 언리얼 시스템의 관리를 받지 않으며 <strong>GC의 관리를 받을 수 없음</strong>

## 2. 리플렉션 데이터 생성 과정

UE에서는 UBT(Unreal Build Tool)와 UHT가 협력하여 다음과 같은 순서로 리플렉션 데이터를 생성하고 관리한다.

- <strong>UBT이 리플렉션 마크업 헤더(generated.h) 탐색</strong> 헤더파일을 스캔하여 UCLASS, USTRUCT,  UPROPERTY 등이 포함된 리플렉션 마크업된 헤더 파일들을 탐지
- <strong>이전 컴파일 이후 변경사항이 있을 경우 UHT가 실행되어 리플렉션 데이터 갱신</strong>
- <strong>UHT이 리플렉션 데이터 빌드 및 C++코드 생성</strong> 헤더 파일을 파싱하여 리플렉션 데이터 빌드, 이 데이터를 기반하여 C++코드(generated.h) 생성
- <strong>UHT이 추가 매크로와 함수 생성</strong> GENERATED_BODY()등의 매크로를 통해 리플렉션 관련 함수와 유틸리티 코드를 추가로 생성
- <strong>리플렉션 데이터 저장 및 동기화 보장</strong> 생성된 리플렉션 데이터는 C++코드로 저장, UE의 직렬화와 동기화가 보장!

<div class="note-box">

언리얼의 리플렉션 시스템(프로퍼티 시스템)은 엔진의 핵심을 이루는 시스템으로, 에디터 통합, 직렬화, 블루프린트, 네트워킹 등 다양한 기능을 지원한다. 따라서, 일반 C++ 클래스를 사용할 경우 이러한 편의 기능(리플렉션, 가비지 컬렉션, 에디터 연동 등)을 보장받지 못하므로 주의가 필요하다.

</div>
