여기까지 간단하게 정리하자면 GameUIManagerSubsystem에서는 어떤 UIPolicy를 사용할지 결정하고(CurrentPolicy) UIPolicy에서는 어떤 Layout을 사용할지 결정한다. 이때까지의 과정으로 돌이켜보자면 Manager가 직접관리해주는 패턴은 아니였다. UI개발방식이 사람마다 다르고 추상화가 높은 컨텐츠 중 하나이다 보니, Lyra에서는 Policy라는 UI정책을 통해 결정을 맡기게 되는것이다. UIPolicy에 따라 UI설정 방식이 바뀐다!
